## Theme and Storyline

**Theme:**

Cybersecurity Data Center Escape

**Storyline:**

The player is an IT security analyst trapped inside a data center that has been compromised by a rogue hacker. The player's goal is to move through the facility, collect six important cybersecurity tools, and avoid the Network Operations Center until all items have been collected. The player must gather an Encryption Key, Access Badge, Firewall Module, Diagnostic Toolkit, Backup Drive, and Security Token. Once all six items are collected, the player can safely enter the Network Operations Center and defeat the rogue hacker. If the player enters the villain's room before collecting all six items, the game is lost.

## Rooms

Project One requires a minimum of eight rooms.

1. Lobby - Start room
2. Network Closet
3. Server Room
4. Monitoring Room
5. Security Office
6. IT Workshop
7. Backup Room
8. Network Operations Center - Villain room

## Items

With the minimum eight-room design, Project One requires at least six items.
Every room except the start room and villain room must contain one item.

1. Firewall Module - Network Closet
2. Encryption Key - Server Room
3. Security Token - Monitoring Room
4. Access Badge - Security Office
5. Diagnostic Toolkit - IT Workshop
6. Backup Drive - Backup Room

## Villain

The villain is a Rogue Hacker who has taken control of the data center's network systems. The hacker is located in the Network Operations Center. The player must avoid this room until all six cybersecurity items have been collected.
